# 소개

DaruDB는 애플리케이션의 데이터를 로컬 파일 하나에 담는 임베디드 데이터베이스이며, Rust로 작성한 엔진 하나를 Rust와 Node.js, Dart 프로그램이 함께 씁니다.

임베디드 데이터베이스는 프로그램 옆이 아니라 프로그램 안에서 돌아갑니다. 설치하거나 띄우거나 접속할 서버가 없습니다. 프로그램이 파일을 열고, 그 안에 객체를 읽고 쓰고, 파일을 닫으면 끝입니다. 데스크톱 애플리케이션이나 모바일 앱, 명령줄 도구, 작은 서버가 자기 데이터를 보관할 때 쓰는 종류의 데이터베이스입니다.

## 설계 목표

모든 결정은 다섯 가지 요구 사항을 따르며, 우선순위도 이 순서입니다.

1. **성능.** 애플리케이션이 흔히 쓰는 임베디드 SQL 엔진보다 빠른 읽기와 쓰기. 같은 내구성 설정에서 측정합니다.
1. **암호화.** 파일 전체를 암호화하고 인증하며, 키를 올바르게 만들고 보관합니다.
1. **안정성.** 크래시나 정전을 겪어도 살아남는 파일, 손상을 알아채고 복구할 수 있는 구조, 여러 프로세스가 파일 하나를 동시에 쓰는 환경.
1. **호환성.** Windows와 macOS, Linux, iOS, Android의 오래된 버전부터 최신 버전까지. 파일 형식은 자기 버전을 기록하고, 파일 형식이나 스키마의 새 버전마다 이전 버전에서 넘어오는 마이그레이션을 함께 제공합니다.
1. **쓰기 쉬움.** 스키마를 선언하기 쉽고 쿼리를 작성하기 쉬우며, 결과는 열린 데이터베이스에 묶인 핸들이 아니라 평범한 객체입니다.

모두 목표입니다. 각 목표는 그것을 증명하는 벤치마크나 테스트가 저장소에 들어온 뒤에야 기능이라고 말합니다.

## 구조

엔진은 Rust로 한 번만 작성합니다. Rust 크레이트가 곧 엔진이고, Node.js와 Dart 패키지는 그 위의 얇은 바인딩으로서 자기만의 동작을 더하지 않습니다. 파일에 관한 규칙은 모두 엔진에 있습니다. 그래서 한 언어에서 쓴 파일을 다른 언어에서 읽어도 똑같이 읽히고, 오류도 모든 언어에서 같은 `code`를 갖습니다.

엔진 안의 각 계층은 자기보다 아래 계층만 씁니다.

| 계층 | 하는 일 |
| --- | --- |
| 객체, 스키마, 쿼리 | 컬렉션과 인덱스, 마이그레이션, 그리고 그 위에서 도는 쿼리 |
| 트랜잭션과 잠금 | 읽는 쪽에는 스냅샷을, 쓰는 쪽은 한 번에 하나로, 프로세스 사이는 파일 잠금으로 조율 |
| 쓰기 시 복사 B+트리 | 커밋한 페이지를 덮어쓰지 않고 레코드와 인덱스를 저장 |
| 페이지 | 고정 크기 페이지를 읽고 쓰며, 페이지마다 체크섬을 두고 설정하면 암호화 |
| 파일 형식 | 파일의 모든 바이트가 뜻하는 바. 헤더에 파일 형식 버전을 기록 |

파일은 매번 오프셋을 지정해 읽고 쓰며, 메모리에 매핑하지 않습니다. 매핑하면 경우에 따라 읽기가 빨라지지만, 다른 프로세스가 파일을 바꿀 때 안전하게 만들 수 없고 페이지 암호화와도 함께 쓸 수 없습니다. 성능 목표는 매핑 없이 달성해야 합니다.

## 현재 상태

지금 저장소에는 앞으로 쌓아 올릴 뼈대가 있습니다.

- Rust 크레이트는 데이터베이스 파일을 만들고, 파일 형식 버전과 페이지 크기를 기록한 헤더를 쓰고, 파일을 다시 열 때마다 그 헤더를 검증합니다. 데이터베이스가 아닌 파일, 다른 형식 버전의 파일, 헤더가 손상된 파일은 어느 경우인지 알려 주는 오류와 함께 거부합니다.
- Node.js 패키지는 그 엔진으로 데이터베이스를 열고 닫으며, 엔진의 오류를 같은 코드로 그대로 전달합니다.
- 두 패키지 모두 테스트가 있고, 이 사이트도 영어와 한국어로 준비돼 있습니다.

아직 데이터베이스에 무언가를 저장할 수는 없습니다. 앞으로 할 일은 이 순서입니다.

1. **저장 커널**: 페이지 파일, 쓰기 시 복사 B+트리, 원자적 커밋. 수천 번의 강제 종료와 정전 시뮬레이션으로 검증합니다.
1. **암호화**: 페이지 암호화와 키 관리. 같은 테스트가 암호화를 켜고 끈 두 경우 모두 통과해야 합니다.
1. **여러 프로세스**: 파일 잠금 프로토콜. 무작위로 강제 종료되는 여러 프로세스를 동시에 돌리는 퍼징으로 검증합니다.
1. **객체와 쿼리**: 스키마와 인덱스, 쿼리, 마이그레이션, 그리고 벤치마크.
1. **바인딩과 배포**: Dart 패키지, 그리고 지원하는 모든 플랫폼용 사전 빌드 바이너리.
1. **도구**: 무결성 검사, 손상 파일 복구, 백업, 압축.
